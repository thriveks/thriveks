Privacy Policy

Code Companion is designed as a local ordinance reference tool. This page explains what information the app does and does not collect.

Code Companion Privacy Policy

Effective date: April 2026

Overview

Code Companion is a searchable reference app for reviewing the Leavenworth Code of Ordinances. The app is designed to help users search ordinance sections, review source text excerpts, and open bundled PDF source material.

Information We Collect

Code Companion does not collect personal information from users through the app.

  • No account creation is required.
  • No login is required.
  • No personal profile information is collected through the app.
  • No ordinance searches are transmitted to a server by the app.

Data Stored in the App

The app uses bundled ordinance reference materials stored locally within the app package, including structured ordinance data, source text excerpts, and a bundled PDF source file. These resources are used only to provide ordinance lookup and reference functionality.

Analytics, Tracking, and Advertising

Code Companion does not use in-app advertising and does not use third-party tracking for advertising purposes. The app is not designed to track users across other companies’ apps or websites.

External Links

The app and related website pages may include links to external sites such as ThriveKS support pages or website pages. If you follow an external link, your interaction with that website is governed by the privacy practices of that external site, not by the local app functionality itself.

Children’s Privacy

Code Companion is a general reference tool and is not specifically directed to children. The app does not knowingly collect personal information from children.

Changes to This Policy

This Privacy Policy may be updated from time to time to reflect changes in the app, its functionality, or related website support resources. Any updated version should be posted on this page.

Contact

If you have questions about this Privacy Policy, please visit the Code Companion support page at thriveks.com/CodeCompanion/support.
